# Contributing

Thank you for your interest in the Supply Chain Control Tower.

This is a public demo/community edition intended for learning,
portfolio, and architecture demonstration purposes.

## How You Can Contribute

- **Report issues** — open an Issue if something is broken or unclear
- **Suggest improvements** — open an Issue with your idea
- **Share what you built** — start a Discussion to show how you used this project
- **Star the repo** — helps others discover the project

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Follow the setup instructions in README.md
4. Make your changes
5. Open a pull request with a clear description

## Guidelines

- Keep changes focused and minimal
- Follow the existing code structure
- Update documentation if behaviour changes
- Test your changes before submitting

## Questions

Open a Discussion or Issue — all questions are welcome.
